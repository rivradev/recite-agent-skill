# Plan: Comprehensive Test Coverage Improvement

**Goal:** Raise coverage from 66% total (`process_receipts.py` 72%, `recite_client.py` 54%) to ≥95% for both files, covering all edge cases.

| Module | Stmts | Missing | Cover |

## Strategy

1. **Create `tests/conftest.py`** — shared `FakeResponse`, `_case_dir`, and `FakeReciteClient` fixtures to eliminate duplication across the 4 test files that currently duplicate them.
2. **Create `tests/test_recite_client_full.py`** — new file covering every untested `ReciteClient` method and edge case.
3. **Create `tests/test_cli_subcommands.py`** — new file covering every untested CLI subcommand handler.
4. **Create `tests/test_cli_main.py`** — new file covering the `main()` entry point, error dispatch, and backward-compat logic.
5. **Extend existing test files** — fill in remaining edge cases in `test_process_receipts_scan_dir.py` and `test_process_receipts_errors.py`.
