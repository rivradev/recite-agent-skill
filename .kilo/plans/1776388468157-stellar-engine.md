# Plan: Add Bank Statements, Bank Transactions & Reconciliation Endpoints

## Goal

Add full support for the 17 missing API endpoints (Bank Statements, Bank Transactions, Reconciliation) so the skill provides the same end-to-end experience as the Recite web UI. All changes follow existing patterns in `recite_client.py` and `process_receipts.py`.

---

## 1. `recite_client.py` — Add Client Methods

Add three new sections after the existing "Usage" section (line 620), following the same docstring and type-annotation patterns used throughout the file.

### 1a. Bank Statements (5 methods)

| Method | HTTP | Endpoint | Key Args |
|--------|------|----------|----------|
| `upload_bank_statement(csv_data: str)` | POST | `/bank-statements` | Raw CSV string (text/csv), sent like `import_csv` — direct `_session.request` with `Content-Type: text/csv` |
| `list_bank_statements(limit, offset)` | GET | `/bank-statements` | Optional pagination params |
| `get_bank_statement(statement_id)` | GET | `/bank-statements/{id}` | — |
| `delete_bank_statement(statement_id)` | DELETE | `/bank-statements/{id}` | — |
| `export_bank_statement(statement_id)` | GET | `/bank-statements/{id}/export` | Returns CSV content |

### 1b. Bank Transactions (4 methods)

| Method | HTTP | Endpoint | Key Args |
|--------|------|----------|----------|
| `list_bank_transactions(statement_id, limit, offset)` | GET | `/bank-transactions` | Optional `statement_id` filter + pagination |
| `get_bank_transaction(tx_id)` | GET | `/bank-transactions/{id}` | — |
| `update_bank_transaction(tx_id, **fields)` | PATCH | `/bank-transactions/{id}` | Arbitrary key=value fields (same pattern as `update_transaction`) |
| `delete_bank_transaction(tx_id)` | DELETE | `/bank-transactions/{id}` | — |

### 1c. Reconciliation (6 methods)

| Method | HTTP | Endpoint | Key Args |
|--------|------|----------|----------|
| `create_reconciliation_link(transaction_id, bank_transaction_id)` | POST | `/reconciliation/links` | Both IDs required |
| `list_reconciliation_links(statement_id, limit, offset)` | GET | `/reconciliation/links` | Optional filters + pagination |
| `update_reconciliation_link(link_id, **fields)` | PATCH | `/reconciliation/links/{id}` | Arbitrary key=value fields |
| `delete_reconciliation_link(link_id)` | DELETE | `/reconciliation/links/{id}` | — |
| `auto_match_reconciliation(statement_id)` | POST | `/reconciliation/auto-match` | Statement ID required |
| `get_reconciliation_summary(statement_id)` | GET | `/reconciliation/summary` | Statement ID required |
| `export_reconciliation(statement_id, format)` | GET | `/reconciliation/export` | Optional format param, statement_id filter |

**Note on `upload_bank_statement`**: Mirrors `import_csv` — must bypass `_request()` and call `_session.request()` directly to send raw CSV with `Content-Type: text/csv`. Extract the shared error-handling logic into a private `_handle_response(resp)` helper to avoid duplication with `import_csv`.

## 2. `process_receipts.py` — Add CLI Subcommands

### 2a. New command handler functions

Add handler functions following the existing pattern (e.g., `cmd_categories` / `cmd_category_add`):

**Bank Statements:**
- `cmd_bank_statements(args, client)` → calls `list_bank_statements`
- `cmd_bank_statement_upload(args, client)` → reads CSV file, calls `upload_bank_statement`
- `cmd_bank_statement_get(args, client)` → calls `get_bank_statement`
- `cmd_bank_statement_delete(args, client)` → calls `delete_bank_statement`
- `cmd_bank_statement_export(args, client)` → calls `export_bank_statement`, writes to `--output` file if given (same pattern as `cmd_export`)

**Bank Transactions:**
- `cmd_bank_transactions(args, client)` → calls `list_bank_transactions`
- `cmd_bank_transaction_get(args, client)` → calls `get_bank_transaction`
- `cmd_bank_transaction_update(args, client)` → calls `update_bank_transaction` with `_parse_kv_list`
- `cmd_bank_transaction_delete(args, client)` → calls `delete_bank_transaction`

**Reconciliation:**
- `cmd_reconciliation_links(args, client)` → calls `list_reconciliation_links`
- `cmd_reconciliation_link_create(args, client)` → calls `create_reconciliation_link`
- `cmd_reconciliation_link_update(args, client)` → calls `update_reconciliation_link`
- `cmd_reconciliation_link_delete(args, client)` → calls `delete_reconciliation_link`
- `cmd_reconciliation_auto_match(args, client)` → calls `auto_match_reconciliation`
- `cmd_reconciliation_summary(args, client)` → calls `get_reconciliation_summary`
- `cmd_reconciliation_export(args, client)` → calls `export_reconciliation`, writes to `--output` file if given

### 2b. Argument parser additions

Add subparsers in `build_parser()`, grouped under three new comment sections:

```
# ── bank-statements ────────────────────────────────
bank-statements         → --statement-id (opt), --limit, --offset
bank-statement-upload   → file (positional CSV path)
bank-statement-get      → id (positional)
bank-statement-delete   → id (positional)

# ── bank-transactions ──────────────────────────────
bank-transactions       → --statement-id (opt), --limit, --offset

# ── reconciliation ─────────────────────────────────
reconciliation-links            → --statement-id (opt), --limit, --offset
reconciliation-link-create      → --transaction-id, --bank-transaction-id
reconciliation-link-update      → id (positional), fields (nargs="+")
reconciliation-link-delete      → id (positional)
reconciliation-auto-match       → statement-id (positional)
reconciliation-summary          → statement-id (positional)
reconciliation-export           → --statement-id, --format, --output/-o
```
